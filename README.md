## What my work changed

- **A screen that kept the payroll team waiting almost 2 minutes now opens in under 2 seconds.** The employee list for a client's HR team (1,192 people) was fetched from the ERP from scratch every time. I added caching over TOTVS RM and measured before and after.
- **Monthly payroll loan checks went from 2 in 3 contracts right to 95 in 100.** I replaced a spreadsheet check with automatic reconciliation between Brazil's Dataprev and TOTVS RM, and grouped 201 scattered alerts into 46 cases the team can act on.
- **The team used to calculate 20+ employee terminations a day by hand.** I automated the flow from request to the official calculation in the ERP, with mobile approval by the board. 1,083 automated tests check the math on every change.
- **Our AI tools stopped starting from scratch.** I created the AIONS Brain, a knowledge base in Git that Claude Code and Codex read and update, used by 9 people, and wrote 22 of the team's 25 AI skills.
